## Projects

### [Fake Account and Threat Detection Engine](https://github.com/pushpam2404/fake_acc)

Python, XGBoost, SHAP, FastAPI, React, NetworkX. Built for a Smart India Hackathon problem statement from ITBP / Ministry of Home Affairs (SIH-1775).

- Two XGBoost classifiers trained on about 101,000 labeled accounts: 90.04% accuracy for X and 96.87% for Meta platforms.
- A noisy tweet-level dataset was holding X accuracy at 67%. Removing it brought the model to 90.04%.
- SHAP explanations shown as plain-English risk factors, a NetworkX graph for coordinated accounts, and PDF case-file export.
- Playwright scraping that never stores credentials.

### [Global Banking ETL](https://github.com/pushpam2404/global-finance-etl)

Python, Pandas, NumPy, BeautifulSoup, SQLite. Scrapes market capitalization data for the largest banks, converts currencies with vectorized operations, and loads the result into SQLite and CSV, with timestamped logging at each stage.

### [KAPS MedTech](https://github.com/pushpam2404/KAPS-Medtech) ([live](https://kaps-medtech.vercel.app))

Node.js, Express, PostgreSQL, JWT, bcrypt. A clinic app where students book doctors and doctors record diagnoses and prescriptions. Built at a 24-hour university hackathon. The repo has 29 integration checks.

### [TripSync](https://github.com/pushpam2404/Trip-Sync) ([live](https://trip-sync-rho.vercel.app))

TypeScript, React, Express, MongoDB, Gemini. A road-trip planner with maps, nearby stops and a chat assistant. Started for Smart India Hackathon 2025. It is still in development.
